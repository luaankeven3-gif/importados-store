# Importados Store

MVP de catálogo demonstrativo desenvolvido com React, TypeScript e Vite, sem uso de créditos do Lovable.

## Executar

```bash
npm install
npm run dev
```

## Compilar

```bash
npm run build
```

## Escopo atual

- Catálogo, busca, categorias e favoritos.
- Botão de interesse com persistência **local no navegador**.
- Produtos demonstrativos, sem estoque ou vendas.
- Sem checkout, pagamento, backend, painel administrativo ou métricas compartilhadas.

## Próximos passos

Adicionar backend seguro, autenticação administrativa, CRUD de produtos, analytics de interesse, proteção contra spam, consentimento/LGPD e integração opcional com WhatsApp. Validar compilação e publicação antes do lançamento.
